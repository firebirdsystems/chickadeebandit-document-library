# Document Library

A [Chickadee Bandit](https://chickadeebandit.com/app-library/document-library) app.

Versioned repository for governing documents — CC&Rs, bylaws, architectural guidelines, rules — plus a chronological archive of board meeting agendas and minutes. The Board uploads and versions files; everyone can always access the current governing docs.

## Features

- Versioned governing documents.
- Chronological archive of agendas and minutes.
- The board uploads and versions; everyone can access the current documents.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-document-library/releases/latest/download/bundle.json
```
